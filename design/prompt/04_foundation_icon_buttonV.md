# 넌지시 디자인 시스템 — 아이콘 버튼

아이코노그래피 프레임을 기반으로 넌지시의 아이콘 버튼을 생성한다.

## 종류
1. Ghost
- 40×40 또는 48×48
- 배경/테두리 없음
- 뒤로가기, 더보기, 닫기, 공유 등에 사용

2. Soft
- 40×40 또는 48×48
- 원형 또는 rounded square
- neutral 또는 brand-subtle 배경
- 즐겨찾기, 취향 편집 등 보조 행동에 사용

3. Accent
- 48×48
- Brand Primary 배경
- 필요 시 명확한 outline 또는 작은 offset shadow 허용
- 정말 중요한 단일 행동에 제한적으로 사용

## 상태
- default
- pressed
- disabled

## 원칙
- 시맨틱 컬러 토큰만 사용
- 아이콘 20 또는 24px
- 최소 터치 영역 40px 이상
- Accent 아이콘 버튼을 반복적으로 배치하지 않는다.
- Primary CTA를 아이콘 버튼만으로 표현하지 않는다.

## 컴포넌트 생성
각 종류 × 상태를 각각 컴포넌트로 생성한다.
아이콘 버튼 자체만 컴포넌트화한다.
