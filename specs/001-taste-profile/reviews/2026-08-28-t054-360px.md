## 1. 무엇을 어떻게 쟀나

수동 클릭 대신 `playwright.config.ts`에 이미 있던 `mobile-360` 프로젝트로 검증했다.

```ts
{ name: 'mobile-360', use: { ...devices['Pixel 5'], viewport: { width: 360, height: 800 } } }
```

측정은 픽스처가 한다 — 눈으로 보는 것보다 정확하고 재현된다.

```ts
// tests/e2e/fixtures/taste-ui.ts  expectNoHorizontalScroll()
expect(viewportWidth, 'SC-006 검사는 뷰포트 폭 360 에서만 의미가 있다').toBe(360)
const scrollWidth = await page.evaluate(() => document.documentElement.scrollWidth)
expect(scrollWidth, `가로 스크롤 발생 — scrollWidth ${scrollWidth} > 360`).toBeLessThanOrEqual(360)
```

> **왜 수동으로 안 했나**: Chrome 창은 360px로 못 줄인다. 최소 창 폭에서 클램프된다
> (330 요청 → 503으로 잘림). DevTools 기기모드나 Playwright 뷰포트가 유일하게 정확한 방법이다.

### 원인

`category-picker.tsx`는 `aria-labelledby`로 **라벨과 현재 값을 함께** 접근 가능한 이름에 묶는다.

```tsx
{/* 접근 가능한 이름 = 라벨 + 현재 값 — 네이티브 select 의 읽기 순서와 같다 */}
aria-labelledby={`${labelId} ${valueId}`}
```

그래서 버튼의 실제 이름은 `"어떤 종류인가요? 카테고리 선택"`인데, 픽스처는 값만으로 exact 매칭했다.

```ts
// 실패: 이름이 정확히 '카테고리 선택' 인 버튼은 없다
await dialog.getByRole('button', { name: currentLabel, exact: true }).click()
```

**컴포넌트가 맞고 테스트가 낡았다.** E2E(`b3a69da`)가 먼저 작성됐고 a11y 커밋(`644c0f5`, 13:37)이
나중에 이름을 바꿨다.

### 왜 아무도 못 봤나

`E2E_USER_EMAIL`/`E2E_USER_PASSWORD`가 비어 있으면 인증 E2E는 **실패가 아니라 skip** 된다.
초록으로 보이지만 한 줄도 안 돈다. 이번에 테스트 계정을 만들면서 처음 실행됐고, 그제서야 드러났다.

> **교훈**: `npm run test:e2e` 결과에서 `passed` 숫자만 보지 말고 `skipped`가 있는지 본다.

### 수정

`tests/e2e/fixtures/taste-ui.ts` — 트리거 전용 로케이터를 두고 이름의 **끝**으로 잡는다.
시트 안 대분류 목록 버튼은 이름이 값 그대로라 그대로 둔다.

```ts
export function categoryTrigger(dialog: Locator, value: string): Locator {
  return dialog.getByRole('button', { name: new RegExp(`${escapeRegExp(value)}$`) })
}
```

### 전원 — 로컬 개발 함정 2가지

1. **`localhost` 쿠키는 포트를 안 가린다.** 다른 Supabase 프로젝트를 `:3000`에 띄워두면
   `sb-*` 쿠키가 같이 쌓여 헤더 상한(16KB)을 넘고 **HTTP 431**로 페이지가 아예 안 뜬다.
   → 브라우저에서 `localhost` 쿠키를 지운다.
2. **개발 서버는 반드시 `:3000`.** `playwright.config.ts`의 `baseURL`·`webServer`가 3000 고정이다.

### 담당자 미정 — Supabase Site URL 이 깨져 있다

Site URL이 스킴 없이 `neonjisi.vercel.app`으로 저장돼 있다. Supabase가 자기 도메인의
**상대 경로로** 해석해서, 폴백이 걸리면 이렇게 끝난다:

```
https://<project>.supabase.co/neonjisi.vercel.app?code=...
→ {"error":"requested path is invalid"}
```

- **고칠 것**: Site URL을 `https://neonjisi.vercel.app`으로
- **같이 볼 것**: Redirect URLs에 localhost 항목이 하나도 없다. 그래서 로컬에서 Google 로그인이
  안 되고 폴백이 걸린다. 로컬 OAuth가 필요하면 `http://localhost:3000/**`를 추가한다.
  (E2E는 이메일/비밀번호 세션 주입이라 이것 없이도 돈다)
