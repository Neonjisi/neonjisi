## 재촬영

```bash
npm run build && npm run start          # 프로덕션 빌드로 띄운다 (dev 오버레이 없음)
npx tsx scripts/pt-shots/shots.mts               # 31장 재촬영
npx tsx scripts/pt-shots/board.mts               # 요약 보드 재생성
```

`scripts/pt-shots/` 의 스크립트는 전부 앱 UI 를 거쳐 데모 데이터를 만든다 (DB 직접 쓰기 없음).
초대 링크 화면의 도메인은 `NEXT_PUBLIC_SITE_URL` 을 채우고 다시 빌드하면 바뀐다 —
빌드 타임에 인라인되는 값이라 런타임 지정은 반영되지 않는다.
